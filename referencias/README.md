# Referencias

Material de apoyo que se usa como guía en el proyecto. No es código ni documentación del negocio.

| Archivo / carpeta | Para qué sirve | En git |
|---|---|---|
| [estructura-proyecto-rag.md](estructura-proyecto-rag.md) | Guía general de estructura para proyectos RAG: carpetas, dependencias, `config.yaml`, `main.py`, estilo de comentarios y tests. Copia global en `~/.claude/instrucciones/`. | Sí |
| [diagramas/](diagramas/) | Guía de formato (`guia.md`) y plantilla HTML (`plantilla.html`) para diagramas de arquitectura de IA. Con ellas se hizo `diagramas/arquitectura-pipeline.html`. | Sí |
| `harness-kit/` | Copia original de la skill `harness-creator`. La versión instalada que usa Claude Code está en `.claude/skills/harness-creator/`. | No (solo local) |
